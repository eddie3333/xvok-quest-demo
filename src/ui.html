What this version can do

Run as a Windows EXE, save your player progress, prepare three-edit plans, organize results, open official sign-in pages, keep an improvement journal and validate downloaded update packages.

Local rendering uses FFmpeg when it is installed. This first version doesn’t replace Kashie’s footage library or your scheduler. Updates are checksum-checked for file integrity; this preview EXE is not code-signed.
